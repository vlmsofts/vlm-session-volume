# VLM Data Gateway — API Reference (RETIRED COPY)

**This copy was retired 2026-09-02.** It was a fork of the gateway's API
reference frozen at 2026-06-17 (2190 lines) and had drifted from the live
API — missing whole endpoint families added since, including `/v1/expiry`,
`/v1/calendar/*`, the GEX endpoints (`/v1/gex/*`, `/v1/flow/*`), and
`/v1/sessionvolume/*`, among others.

**The single authority is:**
- `vlm-data-gateway\VLM_API_REFERENCE.md` (in the `vlm-data-gateway` repo), and
- the live, machine-readable catalog at `GET /v1/catalog`
  (`https://vlmapi.vlmdata.com/v1/catalog`).

Read one of those before building against any endpoint. Do not resurrect this
file's content — it is git-tracked, so the old copy remains recoverable from
this repo's git history if it's ever needed for archaeology, but it should
not be used as a live reference going forward.
